Here is the sequence of steps to install Vim mode in DBeaver using the Vrapper plugin:

Open DBeaver.

Go to the main menu and select Help -> Install New Software.

In the "Work with" field, enter the update site URL for Vrapper:
https://vrapper.sourceforge.net/update-site/stable

Press Enter to load the available plugins from this site.

Select the Vrapper plugin from the list.

Click Next and follow the installation wizard prompts to install the plugin.

After the installation completes, restart DBeaver to activate the plugin.

Now you can toggle Vim mode in the SQL editor using the Vrapper controls or keybindings.

This will enable Vim-style editing inside DBeaver for working with SQL queries. If there are issues with installing from the Eclipse Marketplace, installing directly from the update site is the recommended method.
